# ChatGPT 提示词与工作流示例（中文）

这里整理可直接改写使用的中文提示词和工作流，帮助初学者把模糊任务变成清楚、可检查的请求。内容面向写作、学习、资料整理和日常办公；不承诺某个模型、账号或服务始终可用。

## 快速开始

1. 说明你要完成的任务和目标读者。
2. 提供必要背景、材料和不能改变的事实。
3. 指定输出格式、长度和判断标准。
4. 先让模型列出缺失信息，再开始产出；涉及事实时要求来源或标出待核实项。

通用模板：

```text
你要完成的任务：{任务}
背景和已有材料：{背景}
必须遵守：{约束}
交付格式：{格式}
验收标准：{如何判断完成}
如果信息不足，请先列出缺失项，不要猜测。
```

## 示例工作流

### 写作提纲
请根据下方材料，为{读者}写一份关于{主题}的提纲。区分已知事实、观点和待核实内容。先给出 3 个结构方案，再说明各自适合的场景。不要补造材料中没有的数据。

### 学习计划
我想在{周期}内学会{主题}，每周可投入{时间}。先用 5 个问题判断我的基础，再安排每周目标、练习和自测题。每周内容应能独立完成。

### 资料整理
从我提供的文本中提取结论、证据、分歧和未知项。每条结论附上原文位置；无法从文本支持的内容标为“未证实”。

## 使用建议

- 把模板中的占位符替换成真实信息，避免把机密或个人信息粘贴到未经确认的服务中。
- 重要决定要独立核对来源；模型输出不能替代专业意见。
- 改进提示词时记录输入、预期结果和实际差异，逐步迭代。
