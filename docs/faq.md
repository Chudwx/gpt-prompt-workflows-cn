# 提示词使用常见问题

## 为什么要写清楚目标和格式？

具体目标、背景和验收条件能让输出更容易检查。没有必要堆叠复杂术语；先说清任务，再根据结果补充约束。

## 可以把模型输出直接当成事实吗？

不可以。对日期、数字、引用、法律、医疗、金融和其他重要信息，应回到可靠的一手来源核实。提示词可以要求模型区分事实与推测，但不能保证内容一定正确。

## 如何处理敏感资料？

不要把密码、访问令牌、支付信息或未经授权的个人资料粘贴到聊天中。使用任何服务前，先阅读其隐私和数据处理说明。

## 推荐链接代表什么？

推荐链接用于访问 AI 商店页面，可能记录流量来源。链接本身不代表特定商品、价格或兼容性承诺；请以页面实时展示和商家规则为准。
